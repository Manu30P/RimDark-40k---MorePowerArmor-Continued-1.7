# RimDark 40k - MorePowerArmor Continued 1.7

*(Español más abajo / Spanish below)*

---

## 🇬🇧 English

**RimDark 40k - MorePowerArmor Continued 1.7** is an unofficial continuation and compatibility update of **RimDark 40k - MorePowerArmor**, originally created by **Portesel** (with assets and base work by **Phonicmas**, **Mewn Goddess**, and **Grim Cheese**).

### Why this repository exists
After the original mod was removed from the Steam Workshop, I (**Manu30 / Merk**) decided to preserve and update it for **RimWorld 1.7** and the current **RimDark 40k** framework so the community can continue using it. It is a truly great add-on for Warhammer 40k runs, and it would be a real shame to let such a well-crafted mod disappear completely.

> **Credits & Respect:** Full credit and respect go to **Portesel** and the original creators. I claim no ownership over their work and mean no disrespect regarding the removal of the original mod. If Portesel ever returns and requests this repository to be taken down, I will remove it immediately.

### 🛡️ What This Mod Adds
Expands the Space Marine armory for **RimDark 40k - Mankind's Finest** with three iconic armor sets:
* **Mk X Phobos Armor** set
* **Mk X Gravis Armor** set
* **Terminator Indomitus Armor** set

### 📋 Requirements & Load Order
Load these mods **before** this add-on:
1. **Harmony**
2. **RimWorld - Biotech** (DLC)
3. **RimDark 40k - Framework**
4. **RimDark 40k - Mankind's Finest**
5. **RimDark 40k - MorePowerArmor Continued 1.7**

### 📥 Manual Installation
1. Click the green **`<> Code`** button at the top of this page and select **Download ZIP**.
2. Extract the folder into your RimWorld `Mods` folder (`...\Steam\steamapps\common\RimWorld\Mods\`).
3. Enable **RimDark 40k - MorePowerArmor Continued 1.7** in the in-game Mod Manager following the load order above and restart RimWorld.
